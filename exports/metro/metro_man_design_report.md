## 4. L3 Dynamic Routing & Policy Architecture

- **Primary Routing Protocol:** Hierarchical Multi-Area OSPFv2 with Border eBGP (RFC 4271)
- **Backbone Topology Tier:** Distributed Multi-Site / Hybrid Cloud Enterprise WAN
- **Area Assignment:** Area 0 Core Backbone + Non-Zero Leaf Areas
- **Border Interconnect:** eBGP Peering
- **Protocol Rationale:** Network spans 4 subnets across multi-site boundaries or hybrid-cloud interconnects. Multi-Area OSPF confines Link-State Advertisements (Type 1 & 2 LSAs) to regional areas via ABR route summarization, preventing remote link flapping from triggering core SPF recalculations. Border routers leverage eBGP (AS 65100) for strict policy-based path-vector isolation and cloud prefix exchange.
